# Paleta de cores do Astro Hellenic

Cada cor tem um nome e dois valores: papiro e modo claro usam o mesmo; o modo escuro usa a cor adaptada.
Os códigos estão sem o símbolo na frente (6 caracteres).

| Cor | Papiro e modo claro | Modo escuro |
|---|---|---|
| Azul egípcio escuro (arroxeado) | 1034A6 | 5F80E7 |
| Azul egípcio claro | 1F5FA3 | 4A8DD4 |
| Preto de tinta | 1A1410 | E2E8F0 |
| Ocre | B5852F | D9AE3F |
| Terracota | A03E25 | CF6044 |
| Laranja (fogo) | D0610F | F28A33 |
| Marrom (terra) | 6B4A2B | AE7C4E |
| Cinza (ar) | 6B7780 | A3ADB5 |
| Verde (WhatsApp) | 4A7C59 | 5FA073 |
| Fundo creme / fundo escuro | FFFDF5 | 1C1917 |

A água usa o azul egípcio claro. Os elementos: fogo = laranja, terra = marrom, ar = cinza, água = azul egípcio claro.
