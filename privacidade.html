Política de Privacidade

Astro Hellenic · atualizada em 06/10/2026

O Astro Hellenic é um software para astrólogos organizarem seus clientes, mapas astrológicos, relatórios e agendamentos. Esta página explica quais dados tratamos, para quê, e como você pode controlá-los.

1. Quem é responsável

O responsável pelo Astro Hellenic é Cássio Pereira. Para qualquer dúvida ou pedido sobre seus dados: cassio15pereira@gmail.com.

2. Quais dados tratamos

  • Dados do astrólogo (quem usa o software): e-mail de acesso e as configurações que ele escolhe (aparência, disponibilidade de atendimento, serviços).
  • Dados dos clientes do astrólogo: o que o próprio astrólogo ou o cliente preenche, como nome, data, hora e local de nascimento, e dados de contato.
  • Dados de agendamento: dia, horário e cliente de cada atendimento marcado.
  • Dados da Google Agenda (somente se o astrólogo conectar a conta Google): a lista das agendas da conta (nomes), os horários em que elas estão ocupados ou livres, e a criação de eventos de atendimento.

3. Como usamos os dados da Google Agenda

Ao conectar a Google Agenda, o software pede só as permissões necessárias:

  • ver a lista de agendas da conta, para o astrólogo escolher quais bloqueiam horário;
  • ver apenas se cada horário está ocupado ou livre, para não oferecer ao cliente um horário em que o astrólogo já tem compromisso;
  • criar o evento do atendimento na agenda escolhida pelo astrólogo, quando um cliente marca um horário.

Não usamos esses dados para publicidade, não os vendemos e não os transferimos a terceiros, exceto aos provedores de infraestrutura que fazem o software funcionar (hospedagem e banco de dados), sob obrigação de sigilo. Não lemos o conteúdo dos seus outros compromissos: usamos apenas a informação de ocupado/livre.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Onde e como guardamos

Os dados ficam em banco de dados protegido por login. A autorização da Google Agenda é guardada cifrada, em área que o navegador não consegue ler; só o servidor do software a utiliza.

5. Seus direitos e como desconectar

  • Você pode desconectar a Google Agenda a qualquer momento em Configurações → Agenda → Desconectar. Também pode remover o acesso em myaccount.google.com/permissions.
  • Conforme a Lei Geral de Proteção de Dados (LGPD), você pode pedir acesso, correção ou exclusão dos seus dados escrevendo para o e-mail acima.
  • Ao pedir a exclusão, apagamos os dados e a autorização guardada, salvo o que a lei nos obrigue a manter.

6. Mudanças nesta política

Se algo mudar de forma relevante, atualizamos esta página e a data no topo.
